# 隐私说明

1. 所有学习数据（卡片、复习日志、计划、收藏、错词、会话、设置）只保存在
   本机浏览器 IndexedDB（数据库 `ielts-word-local`），应用不发出任何携带
   学习数据的网络请求。
2. 没有账号系统、云同步、统计埋点或第三方 SDK。
3. 备份导出为本地 JSON 下载，由用户自行保管；导入只解析 JSON 数据，不执行
   文件中的任何脚本。
4. 原始 PDF 词书不进入 Git 仓库、`public`、`dist` 或部署产物；页面常驻
   「词书仅供个人学习使用」声明，不提供词书下载。
5. 清除浏览器网站数据会删除学习记录，请定期使用设置页的「导出数据」。
6. 部署在 Cloudflare Pages（静态文件托管）；如需仅本人访问可另行配置
   Cloudflare Access 邮箱白名单。
